# sql-and-duckdb-playbook

> **DE Portfolio — Project 2 of 7** | Phase 1: Foundations

A reference playbook of advanced SQL patterns using PostgreSQL and DuckDB.

## 🎯 Objectives

- Demonstrate advanced SQL: window functions, CTEs, recursive queries, explain plans
- Use DuckDB as a fast local analytical engine
- Query Parquet files directly with DuckDB
- Benchmark the same queries across PostgreSQL and DuckDB

## 🛠️ Stack

| Technology | Purpose |
|:---|:---|
| PostgreSQL | Primary relational engine |
| DuckDB | Local OLAP engine / Parquet querying |
| Python | Query runner & benchmarking scripts |
| Jupyter Notebooks | Interactive exploration |
