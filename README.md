# sql-and-duckdb-playbook

> **DE Portfolio — Project 2 of 7** | Phase 0: Complete

A SQL portfolio project demonstrating advanced PostgreSQL patterns and DuckDB as
a benchmarked alternative OLAP engine, built on the industry-standard TPC-H
dataset (`sf=1`, ~1 GB, ~6 M `lineitem` rows).

## Quick Start

```bash
# 1. Clone and install dependencies
uv sync

# 2. Copy env template and fill in credentials
cp .env.example .env

# 3. Start PostgreSQL
docker compose up -d

# 4. Generate TPC-H Parquet files (~30–60 s)
uv run python scripts/generate_data.py

# 5. Seed PostgreSQL (~1–3 min)
uv run python scripts/seed_postgres.py

# 6. Start JupyterLab
uv run jupyter lab
```

## Stack

| Tool | Role |
|:---|:---|
| PostgreSQL 16 (Docker) | Primary SQL engine — window functions, EXPLAIN plans |
| DuckDB | In-process OLAP engine — benchmarking, Parquet querying, `postgres_scan` |
| Python 3.12 | Scripts and notebooks |
| uv | Package management |
| Jupyter | Notebook execution and narrative |
| pandas + matplotlib | Benchmark results and visualisation |
| pydantic-settings | `.env` validation — fail-fast at startup |
